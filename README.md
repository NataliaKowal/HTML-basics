# HTML Basics

A set of practice pages I made while learning **HTML** and basic **CSS**: text elements, links and images, tables and forms.

## Pages

| File | Page | What it practises |
|---|---|---|
| [`Html_Basics.html`](./Html_Basics.html) | Pigeon Racing | Headings, paragraphs and text structure in an article about pigeon racing |
| [`TextElements.html`](./TextElements.html) | Pet Sitting Instructions | Headings, ordered and unordered lists (care instructions for a dog and a goldfish) |
| [`home.html`](./home.html) | My Stuff | Links to external pages and anchors within the page, images with `alt` text |
| [`contact.html`](./contact.html) | Contact | A simple page with a link back to the home page |
| [`Tables.html`](./Tables.html) | Tables Exercise | A table with header, body and footer, styled with CSS |
| [`Forms_part2.html`](./Forms_part2.html) | Forms Basics | Login form, input types (email, URL, number), `name` attributes and labels |
| [`Forms.html`](./Forms.html) | Checkout Form | Drop-down list, radio buttons, checkbox and submit button |
| [`styles.css`](./styles.css) | Stylesheet | Table styling (borders, padding, colours, alternating rows) and image size |

## How to view

Clone the repository and open any `.html` file in your web browser:

```sh
git clone https://github.com/NataliaKowal/HTML-basics.git
```
